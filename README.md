# 灵山 · 悟空试炼

原创西游题材浏览器 3D 战斗原型。包含八个章节：前置教学、山间赶路、竹海寻符、落石栈道，以及三场不同机制的 Boss 试炼，支持手机横屏触控和桌面键鼠。不是《黑神话：悟空》的完整端游移植，也不包含其原版模型、贴图、音乐或剧情。

在线游玩：https://ling-shan-wukong-trial.yanglinchasel.chatgpt.site

源码：https://github.com/LinYangBIT/ling-shan-wukong-trial · 原创代码采用 MIT，第三方许可见文末。

## 运行

从本目录执行 `python3 -m http.server 5175 --bind 127.0.0.1 --directory dist`，访问 `http://127.0.0.1:5175`。无需安装依赖或构建；Three.js、字体和程序资源均随站点提供。需要 WebGL 2 浏览器。

微信小游戏适配已单独提供：`npm ci && npm run build:wechat` 生成 `wechat-build/`。AppID 配置、导入开发者工具、验证与发布步骤见 [WECHAT.md](WECHAT.md)。本地构建不代表已在微信上线。

## 山海行记

1. **山溪习武**：实际完成移动、木桩三次轻击、重棍、闪避、定身和饮酒六项教学。教学结束前不会进入战斗；木桩不会攻击。
2. **云溪山径**：沿约 140 米曲折石径赶路，途经听瀑桥与桃花望云亭。路线卡显示下一个地标和距离，M / 顶部「山川行记」查看全程地图。
3. **雾隐古刹**：抵达山门后迎战原有白鬃守山妖将，保留横扫、裂地与半血震怒。入场前补满状态。
4. **登云天阶**：战胜妖将后点击「补给 · 继续登顶」，穿过独立的云海石阶，进入山顶圆台。
5. **青岚之巅**：第二 Boss 为四足灵鹿，使用有地面预警的远程风刃和锁定直线的冲锋。横向闪避，趁冲锋后的硬直近身反击；半血后攻势加强。
6. **月下竹海**：沿月光下的溪流与竹林寻找三枚灵符。靠近即可拾取，集齐后开启尽头的月门；路线卡指向尚未找到的灵符。
7. **赤霞栈道**：穿过红枫、熔岩与悬崖之间的栈道。金色圆圈预告落石位置，向栈道另一侧绕行；被落石击中损失生命。
8. **熔岩石猿**：第三 Boss 擅长地面冲击波与锁定位置的陨石。用三次重棍击碎岩甲，抓住七秒破甲窗口输出；普通轻棍和轻棍三连的末段不能破甲。半血后落石连击增加。

主菜单的「关卡选择」可直接进入八个章节。从中途章节开始的练习不会累计完整通关记录；从「山溪习武」开始并击败最后的石猿，才计入三劫通关次数与最佳用时。

失败后重试当前关卡，补满生命、法力、气力及三口葫芦，不需要重走教学；月下竹海重试会重新收集灵符。原有单场、双劫历史记录保留，新增三劫记录使用独立字段 `journeyWins` / `journeyBest`。每章入口会自动保存行记；刷新或重新打开同一浏览器后点击「继续行记」，从保存的章节入口重新出发并补满状态，保留难度、练习标记与此前章节用时。不会保存关内的生命、灵符或即时战斗位置。通关清除本次行记；「重新修行」会从教学覆盖旧行记。存储仅在本机浏览器，没有跨设备同步。原过场仍用于守山妖将入场、震怒与失败；灵鹿和石猿使用即时提示。

## 操作

- WASD / 左侧摇杆：移动；拖动右侧空白区域：调整镜头。
- Shift / 疾行：山路探索中加快赶路，桌面按住、触屏切换；不消耗战斗气力，战斗与教学中关闭。
- J / 棍击：三段连击；K / 重棍：消耗棍势重击。
- 空格 / 闪避：消耗气力，提供短暂无敌。
- 1 / 定身：消耗法力，冻结 Boss；R / 饮酒：恢复生命，每战三次。
- Q / 锁定：切换当前敌人或木桩锁定；Esc：暂停；M：路线地图。

三段轻击分别为横扫、反撩、旋身下砸；重棍包含蓄势、前移、起跳和落地。命中时有短暂顿帧、受击后仰、武器轨迹和伤害数字，连招过程中可预输入下一次轻棍或重棍；起手时过早按下的闪避会短暂缓冲，进入可取消时机后执行。暂停、失焦与换关都会清理输入，闪避可取消排队中的连击。

新增入场（10秒）、妖将震怒（5秒）、胜利（7秒）、失败（4秒）实时3D过场，配有运镜、角色演出、字幕、电影画幅和原创音效。点击「跳过」或按空格/Enter/Esc 可跳过。过场期间暂停战斗计时与伤害；声画设置可关闭自动过场，主菜单「过场鉴赏」可随时重看，不改变通关记录。

Boss 半血后进入第二阶段。声画设置可切换画质、下一战难度、总音量、背景音乐音量和动作音效音量，并可导入本地音乐。通关次数与最佳用时存于本地浏览器。默认音量为 80%，保留手动音量偏好。音乐默认开启，在浏览器允许时尝试自动播放，受限时由首次点击、触摸或键盘操作启用；山路、月林、险道与 Boss 使用不同配器，切场不叠加循环。挥空、轻重命中、落地与 Boss 招式有独立原创合成音效。全屏和横屏锁定依浏览器支持；iPhone Safari 等浏览器可手动旋转设备。

## 实现与限制

`dist/main.js` 管理关卡进度、输入、战斗、相机、界面和存档；`journey-world.js` 生成连续山间路线；`campaign-props.js` 提供习武木桩、云海天阶与山顶战场；`spirit-boss.js` 提供灵鹿模型、风刃与冲锋 AI；`expansion-world.js` 提供月下竹海、灵符收集、赤霞栈道、落石与熔岩竞技场；`stone-boss.js` 提供石猿模型、岩甲、冲击波与陨石 AI；`world.js` 生成原创关节模型、古寺、竹林及 1024×1024 纹理；`audio.js` 合成原创五声音阶氛围音乐及战斗音效；`progress.js` 校验并存储章节行记；`scenic-details.js` 提供原创山脊、竹叶、水纹与软雾。没有游戏原版 BGM，导入音乐仅在本机内存使用，不上传到服务端。场景是风格化程序建模，不是端游写实资产。包含三个双阶段 Boss。山路是有边界的连续路线；没有装备树、开放世界任务系统或联网多人。

高画质最高 2× 设备像素比并启用 2048 阴影，均衡最高 1.35× / 1024 阴影，流畅最高 1× 且关闭阴影。真机帧率取决于手机 GPU；软件渲染器测试不代表真实手机性能。

## 本地验证

- `node --test qa-audio.mjs qa-progress.mjs`：音频生命周期、独立音量与损坏行记恢复。
- `node qa-optimization.cjs`：疾行、连招缓冲、章节续玩、触控能力与音频状态回归。


- `node --test qa-spirit.mjs`：灵鹿风刃、冲锋、冻结、回调清理与场景稳定性测试。
- `node qa-expansion-world.mjs`：新场景路面、符收集、出口条件、落石预警/伤害/清理和场景重置，共 20 项检查。
- `node --test qa-stone.mjs`：岩甲、破甲窗口、冻结、冲击波、陨石、阶段与回调清理，共 16 项检查。
- 先运行 `npm run dev`，再执行 `node qa-journey.cjs`：键盘完成教学及两段山路，检查关卡切换、实际轻重棍、重试、过场、记录和 844×390 布局。Boss 胜负边界采用测试页面内的受控状态；无声测试环境关闭 AudioContext，不验证音频设备。
- `node qa-expansion.cjs`：键盘收集三符、栈道赶路、实际轻重棍破甲、落石伤害、当前关卡重试、练习与完整记录隔离、关卡选择及手机横屏布局，共 19 项检查。胜负与存档边界使用受控状态。
- `node qa-preview.cjs`：未经注入的正式页面，使用真实动画循环、渲染及键盘移动检查。

浏览器脚本依赖 `npm ci` 安装的 Playwright，默认使用 Mac 安装的 Chrome；其他环境通过 `CHROME_PATH` 指定 Chromium 可执行文件。报告保存在项目根目录，截图在 `evidence/`。软件渲染检查不代表手机真机帧率。
